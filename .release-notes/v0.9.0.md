# MySCUT v0.9.0

## 主要更新

### 课表

- 现在课表遇到长单词会换行
- 修复课表导航栏手册轻触失效问题

### 手册

- 修正安卓设备上手册页面某些细微的返回行为
- 更新手册至 85f34ed

### 小组件

- 新增 Android 课程小部件，有竖条与卡片两种样式，各自提供 4×2 宽版和 2×2 紧凑版
- 现在课程结束时小部件会精确刷新
- 现在小部件背景会和全局主题同步
- 加入四种小组件的预览
- 页脚改为动态的剩余课程提示，并新增开关控制是否显示
- 空状态拆分为 “今日无课” “今日课程已结束“ “距离开学还有 X 天” 与 “学期已结束”
- 小组件移除校区前缀
- 紧凑组件日期改为简写形式
- 现在四种课表小组件支持垂直滚动，展示当天全部尚未结束的课程，不再限制为两节
- 避免空时间产生多余分隔符
- 修正课程时间范围格式，统一使用 en dash
- 各种小部件布局修正
- 现在今日无课或今日课程全部结束后，宽版小组件的页脚不再隐藏，改为显示明日安排

### 安卓

- 清理 Manifest 权限与 Provider 配置，将相机声明为非必需，并为列表服务声明 BIND_REMOTEVIEWS 权限
- 修正四个 Provider 的系统时间广播名称
- 加入 Nightly 版图标
